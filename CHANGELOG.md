## Unreleased (3.3.0)

- First version. Serve `protoc`-generated gRPC services on the Dox HTTP/2 server with `Grpc.register(service)`. Unary, server streaming, client streaming and bidi calls, Dox middleware before each call, deadlines (`grpc-timeout`), cancel, metadata, `GrpcStatus` and `GrpcException` (a `GrpcError` from `package:grpc` works too), status details, gzip, message size limits (4 MiB by default), and the `grpc.health.v1` health service. A health change in one isolate goes to all isolates. A call to an unknown service gets `UNIMPLEMENTED`. A middleware error (eg. 401) goes to the client as a gRPC status. The gRPC routes skip `RequestTimeout`. `Grpc.register` throws a clear error when a prefix or group changes the route path. `GrpcOptions.idleTimeout` (off by default) ends a call with no message in or out. A request error reaches the method as an error in its request stream, and a unary method runs only with one whole message. A bad `grpc-timeout` or compressed flag is `INTERNAL`.
